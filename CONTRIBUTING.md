# Contributing

## Ground rules

- No build step, no dependencies, no framework. If a change needs a toolchain, argue for it first.
- One file stays one file until there is a reason for more.
- Anything that pauses the game to explain itself is suspect.

## Where the work is

- AI that plans a multi-stage assault instead of a single push.
- Playable aftermath for both endings.
- Verticality in the raycaster.
- Balance past brood three.

## Style

- Two-space indent, single quotes.
- Name things after what they do to the player, not after the code.
- Keep the species table data-driven; a new enemy is a row, not a new branch.
